# よさんドライブ

日本の普通乗用車向けに、通行料とガソリン代の片道見積もりを予算と比較する Web アプリ。

## ローカル起動

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ブラウザで http://127.0.0.1:8000 を開くと、東京駅から箱根湯本駅のサンプルを確認できます。デモの地図と料金・所要時間は説明用です。

## 実際の経路の検索

Google Cloud で課金を有効にし、Maps JavaScript API と Routes API を有効にします。ブラウザ用 API キーのウェブサイト制限に利用する配信元を設定し、API 制限は有効にした二つの API に絞ります。アプリの「検索設定」でキーを一度保存すると、同じブラウザ・アプリで次回も使えます。キーはその端末のサイトデータに保存されます。共有端末では保存のチェックを外してください。削除するにはキーを空欄にして「保存」を押します。

通常の候補と有料道路を避ける候補を取得し、予算内の候補を所要時間順に表示します。予算判定は取得できた候補が対象です。通行料が不明な候補は料金不明と表示します。ガソリン代は距離 ÷ 燃費 × 単価を円単位で切り上げます。

## Firebase Hosting で配信

Firebase コンソールで利用するプロジェクトを用意し、Firebase CLI を使ってこのフォルダから配信します。`firebase.json` が `dist/` を配信するよう設定済みです。

```sh
firebase login
firebase deploy --only hosting
```

`.firebaserc` で既定の配信先を `budget-navi` に設定しています。デプロイ後に表示される Hosting URL をスマホで開いてください。通常の Hosting URL はアクセスできる人に公開されます。

実際のルート検索を使う場合は、Google Cloud の Maps 用ブラウザキーのウェブサイト制限に、使う Hosting URL（例 `https://budget-navi.web.app/*`）を追加します。公開先の「検索設定」でキーを一度保存してください。

## スマホのホーム画面に追加

スマホから開ける HTTPS の URL に `dist/` の内容を配信します。Mac の `127.0.0.1` は Mac 内での動作確認用です。

- iPhone は Safari の共有メニューから「ホーム画面に追加」を選びます。「Webアプリとして開く」が表示されたらオンにして追加します。
- Android は Chrome で「インストール」ボタン、またはブラウザのメニューから「ホーム画面に追加」を選びます。

端末やブラウザを変えたとき、ホーム画面版で保存済みキーが引き継がれないとき、サイトデータを削除したときは、使うアプリ側で一度設定してください。初回読み込み後は画面をオフラインでも開けます。実際のルート検索と Google Maps の表示にはネット接続が必要です。

アプリのファイルを変更したときは `dist/sw.js` のキャッシュバージョンを更新します。
